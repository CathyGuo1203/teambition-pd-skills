# Teambition WBS 拆解与创建技能

本技能通过对话引导用户输入项目信息，利用 AI 自动进行 WBS 拆解，生成专业的 Excel 预览文件，并在用户确认后调用 Teambition MCP 工具批量创建任务。

## 核心工作流

执行本技能时，请严格按照以下 5 个阶段进行：

### 1. 输入与意图解析

- **收集输入**：接收用户的文字描述、上传的文件（如 PRD、会议纪要）或语音输入。
- **提取上下文**：提取项目背景、整体目标、关键时间节点和潜在的参与角色。
- **项目推断**：
  - 调用 `dingtalk-teambition` 的 `query_projects.py --tql "involveMembers = me()"` 查询用户参与的项目。
  - 若只有 1 个项目，自动选定并告知用户；若有多个，展示列表让用户选择。

### 2. 智能 WBS 拆解

根据提取的上下文，采用自顶向下的策略进行拆解。**必须遵循 `references/breakdown-rules.md` 中的拆解标准。**

- **层级结构**：
  - **Epic**：大功能模块或阶段。
  - **Task**：具体任务，必须满足"单一交付物、验收可量化、体量可控（1-2天）、独立可测"的标准。
- **字段预填**：尝试为每个 Task 预填标题、执行者、截止时间、优先级。

### 3. 渐进式完善

- **检查缺失**：扫描拆解结果，找出缺失的关键字段（执行者、截止时间）。
- **追问机制**：最多进行 3 轮追问，优先追问影响项目推进的核心字段。
- **容错处理**：若 3 轮后仍有非标题必填字段未明确，则留空继续，并在创建后提示用户手动补充。

### 4. Excel 预览与人工确认

- **生成预览**：使用 `excel-generator` 技能的规范，生成包含 WBS 结构的 Excel 文件。
  - **Sheet 1: Overview**：项目总览、任务统计。
  - **Sheet 2: WBS Details**：详细的 Epic 和 Task 列表，使用缩进体现层级，使用条件格式高亮优先级。
- **发送确认**：将 Excel 文件作为附件发送给用户，并请求确认："请查看附件中的 WBS 拆解方案，确认无误后我将为您在 Teambition 中批量创建任务。您也可以直接告诉我需要调整的地方。"
- **禁止静默创建**：在用户明确回复确认之前，**绝对不允许**调用 API 创建任务。

### 5. 批量创建与反馈

用户确认后，执行以下操作：
- **ID 转换**：调用 `query_members.py` 将执行者姓名转换为 `userId`。
- **优先级映射**：调用 `get_priority_list.py` 获取企业真实优先级配置，进行映射。
- **批量创建**：
  - 循环调用 `create_task.py`。
  - 先创建 Epic 级别的任务（或任务分组），获取其 ID。
  - 将 Epic ID 作为 `--parent-task-id` 传递给子 Task，建立层级关系。
- **结果反馈**：向用户发送成功卡片，包含新创建任务的汇总链接（`https://www.teambition.com/project/{projectId}`）。
